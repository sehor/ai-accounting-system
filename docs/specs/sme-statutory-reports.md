# 小企业会计准则法定报表

## 范围

首版只为 `SME/2011-17`（兼容账套传入的 `SME/v1`）提供人民币法定资产负债表和利润表。企业会计准则账套继续使用原有逐科目报表。首版不提供公式编辑、打印、Excel 导出或外币折算。

## 接口

`GET /v1/ledgers/{ledgerId}/reports/statutory/{reportType}?periodCode=YYYY-MM`

`reportType` 为 `balance-sheet` 或 `income-statement`。响应包含模板、准则版本、期间、两列标题、一个或两个分组、法定行及勾稽检查。所有法定行始终返回，未匹配科目按零处理。

利润表两列为“本年累计金额”和“本月金额”；资产负债表两列为“期末余额”和“年初余额”。金额使用账套本位币，首版仅接受 CNY。

## 公式口径

- 利润表本月取选定期间发生额，本年累计取当年首个可用期间至选定期间发生额。
- 资产负债表期末取选定期间期末余额，年初取当年首个可用期间期初余额。
- 科目余额先按叶子科目计算，再通过已有余额投影/递归查询汇总到父科目。
- 应收账款、预付账款、应付账款、预收账款的异常借贷方向按小企业会计准则重分类。
- “未分配利润”兼容尚未自动结转损益的系统状态，纳入“本年利润”和“利润分配”余额。
- 公式只允许标准包声明的白名单操作：`ACCOUNT_BALANCE`、`ACCOUNT_ACTIVITY`、`RECLASSIFIED_BALANCE`、`LINEAR_COMBINATION`。

资产负债表勾稽关系：15、20、29、30、41、46、47、52、53 行；利润表勾稽关系：21、30、32 行。服务返回差额检查，前端在检查失败时显示警告但不隐藏报表。

## 前端行为

SME 报表使用单月选择器。利润表按“项目、行次、本年累计金额、本月金额”展示；资产负债表按“资产”和“负债和所有者权益”左右并列展示。金额右对齐、两位小数、千分位，零值留空，负数保留减号；窄屏保留表格语义并允许横向滚动。
