# ADR-002：科目余额异步投影

## 状态

已接受，首期实现主科目期间余额；辅助核算余额留待后续阶段。

## 决策

凭证、凭证明细和已确认期初余额继续作为唯一事实源。过账、反记账和期初确认在原事务内写入不可变余额事件；应用内 worker 按账套期间顺序异步更新 `account_period_balance`。报表在投影处于 READY 且事件积压不超过配置阈值时读取投影，否则回退现有事实汇总 SQL。

投影不物化父级科目；父级余额由科目树递归汇总。关账取得期间锁并要求投影水位追平且逐科目核对一致，重开只清除余额的 `finalized_at`。投影表可按事实源删除重建，数据库表结构不随回滚删除。

## 发布与回滚

先以 `legacy` 读取模式部署并关闭 worker，维护窗口内按账套重建并核对，随后开启 worker 和 `auto` 模式。发现问题时将 `accounting.balance.read-mode` 改回 `legacy`；事件生产和表结构保留，便于继续核对或重建。

## 取舍

首期只支持账套本位币和主科目，避免把维度组合规范化与报表分组同时引入。最终一致性换取报表稳定的低延迟，超过最大延迟时宁可使用事实源查询。
