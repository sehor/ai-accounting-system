# ADR-003：逐期、全层级科目余额快照

## 状态

已接受，取代 ADR-002 中“不物化父科目”和“投影只保存当期发生额”的决定。

## 决策

`account_period_balance` 是“账套 × 会计期间 × 科目”的稀疏余额快照，保存期初借贷、当期发生借贷、期末借贷六个金额。余额以有符号净额计算后拆分，同一时点借贷最多一方非零。首期从已确认期初余额开始，后续期间的期初等于上期期末。

投影先计算叶级科目，再把所有叶级科目汇总到每一级祖先。父科目发生额分别累加借贷，期初和期末按有符号余额净额拆分。六个金额全为零的行不保存，缺行解释为零。

已记账凭证事实和幂等 outbox 事件必须在同一事务提交。worker 以账套为串行单位，从最早受影响期间重算到最后期间；一次传播的所有期间和层级在一个事务完成。期间在事件入队时立即进入 pending，传播成功后才恢复 READY。重建任务同样总是延伸到当前最后期间。

READY 查询从起始期间快照取期初、从所选范围快照汇总发生额、从结束期间快照取期末。明细账只额外读取范围内的分录。pending、FAILED、REBUILDING 或未初始化时回退事实查询，并通过 `X-Balance-Source`、`X-Balance-As-Of` 和 `X-Balance-Lag-Ms` 响应头公开来源与水位。

## 约束

- 期初余额只能在账套首个会计期间录入并确认。
- 已记账凭证不能删除，只能冲销；草稿变化不产生余额事件。
- 生产业务代码不得绕过凭证写入边界，也不得提供 Noop 余额投影实现。
- 本阶段只投影账套本位币和会计科目层级，不投影辅助核算维度。

## 运维

重点监控传播/重建失败计数、处理时长、水位延迟和事实回退比例。投影异常时保持 worker 和事件生产，查询自动回退；修复后从最早异常期间提交重建，系统会自动重建至最后期间。
