# 开出发票

只保留本插件的往来科目约定：

- 已确认的主营业务客户往来使用应收账款。
- 已确认的非核心往来使用其他应收款。
- 仅有发票而无法确认业务实质时，不推断收入、税额或往来科目。

## 复用数据处理工具

使用插件内置 `scripts/process-sources.mjs invoices` 读取发票汇总表，保留行号、金额和红冲状态，再按业务证据判断科目。 每次任务直接调用现有工具，不另写读取、分类或核对脚本，不在资料目录保存中间文件。调用方式和异常处理见[工具说明](../../scripts/README.md)。
