# 开出发票模板

来源：通用经验“会计记账通用判断与复核原则”。当前通用经验未提供单独的“开出发票”完整借贷模板，因此不得补充未被确认的收入或税额科目。

| 判断项 | 模板 |
| --- | --- |
| 入账依据 | 结合发票、合同和业务摘要判断业务实质。 |
| 主营业务客户往来 | 使用应收账款。 |
| 非核心往来 | 使用其他应收款。 |
| 摘要 | 使用“收货款”等简短、保留业务实质的摘要。 |

若需要完整开票分录模板，先将经确认的规则沉淀为新的通用经验，再更新本 Skill。
