# 月末简便结转销货（劳务）成本

仅在用户要求简便结转时使用。按本会计期间的收入明细分别计算，不替代进销存或项目成本核算。

## 必需信息

- 确认目标账套和会计月份。
- 取得用户提供的毛利率；未提供时必须询问，不得自行估计或沿用历史比例。允许统一毛利率或各收入明细分别提供，统一换算为 `0 ≤ 毛利率 ≤ 1`。
- 确认每个“主营业务收入”明细科目对应的“主营业务成本”明细科目，以及贷方的“库存商品”“劳务成本”等明细科目。无法从账套历史确定映射时询问用户。

## 计算与封顶

1. 检查目标月份是否已有同用途的成本结转凭证；存在时先复核或调整，不要直接重复生成。
2. 查询“主营业务收入”下各末级明细科目在目标月份的本期贷方发生额；不要同时使用父级汇总和子级金额。
3. 对每个收入明细计算：`计划结转成本 = 本期贷方发生额 × (1 − 毛利率)`，按账套本位币精度舍入。
4. 查询对应“库存商品”“劳务成本”等贷方科目在制单前的可用结存额。实际结转额取 `计划结转成本` 与 `可用结存额` 的较小值；可用结存额不为正时取零。
5. 多个收入明细共用同一贷方科目且余额不足时，按各自计划结转成本的比例分摊可用结存额，并处理舍入尾差，合计不得超过该科目的可用结存额。
6. 跳过实际结转额为零的分录，并报告计划金额、实际金额和因余额不足未结转的差额。

## 分录

- 借：对应的“主营业务成本-销货成本”或“主营业务成本-劳务成本”等明细科目。
- 贷：对应的“库存商品-xxx”“劳务成本-xxx”等明细科目。

例如，某销货收入明细本月贷方发生额为 100,000，毛利率为 30%，计划结转成本为 70,000；对应库存商品仅结存 50,000 时，只结转 50,000，并报告 20,000 未结转，结存不得出现负数。
