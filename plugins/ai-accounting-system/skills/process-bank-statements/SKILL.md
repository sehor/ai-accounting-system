# 银行流水分录模板

来源：通用经验“银行流水记账注意事项”“会计记账通用判断与复核原则”。银行流水只证明资金收付；银行科目必须使用账套中的精确银行明细。

| 业务 | 借方 | 贷方 |
| --- | --- | --- |
| 收到有“货款”“合同”或“项目”证据的主营款项 | 银行存款—对应银行 | 应收账款 |
| 支付有“货款”“合同”或“项目”证据的主营款项 | 应付账款 | 银行存款—对应银行 |
| 支付已入账的日常费用 | 其他应付款—对应供应商 | 银行存款—对应银行 |
| 银行手续费 | 财务费用—手续费 | 银行存款—对应银行 |
| 存款利息 | 银行存款—对应银行 | 财务费用—利息收入 |
| 贷款利息 | 财务费用—利息费用 | 银行存款—对应银行 |
| 同名主体、不同银行账户的内部调拨 | 其他应收款—内部往来 | 银行存款—转出银行 |

证据不能判断主营性质时，不生成收入或费用分录。
