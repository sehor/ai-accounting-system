# 个人费用报销

通过 `operate-ai-accounting` 选择账套、核对科目及已有凭证，并使用 accounting MCP 记账。

## 个人往来

- 以报销人为债权人：确认报销时借记对应费用、资产及有证据支持的进项税，贷记“其他应付款—报销人”。使用账套已有个人明细，缺少时按科目创建流程处理。
- 发票上的商户、平台、物流公司是消费凭据中的销方，不是本次报销的应付对象。个人已垫付、公司向个人报销的支出，不新增对发票销方的应付款。
- 实际支付报销款时，借记“其他应付款—报销人”，贷记实际付款银行。只有报销表写着付款账户，不足以证明已付款；结合银行记录核对，已入账付款不得重复记账。
- 公司直接向供应商付款的业务走采购、收票或银行付款流程，不混入个人报销处理。

## 已入账发票

- 逐项核对发票或收票明细、历史凭证和报销明细，区分未入账费用、已入账费用及已确认个人应付款；核对销方、日期、项目、金额和税额，金额相同本身不足以判定同一业务。
- 对确属同笔个人垫付、此前挂在供应商名下的发票，优先在可修改期间将原凭证对应贷方金额改挂报销人，保留原费用和税额。只调整已核实的报销部分，不将供应商全部余额转给个人。
- 原凭证已确认的个人应付款，不在报销凭证中再次确认；报销凭证只补记尚未入账的部分。按个人核对“原凭证确认额＋本次补记额＝本次报销总额”。
- 若原凭证无法修改，按系统约束处理必要的往来重分类，并说明原因；重分类不代表还要向供应商付款。报销结算对象始终是个人。

## 金额、归属与摘要

- 根据实际用途和账套已确认口径选费用科目，不仅凭报销表项目标签判断。明细与备注总额矛盾或跨月归属不清时，核对后采用用户确认的金额和期间。
- 进项税以可核实的发票信息为依据，不仅凭“专票”备注推算税率或税额。用户确认按含税金额处理时，按含税金额计入对应费用，避免重复抵扣已入账税额。
- 凭证摘要和分录摘要保持简短，使用“报销X月日常费用”；用户指定文字时，逐字采用。核对过程、文件名、税额待核事项和用户确认经过保留在工作证据或必要的结果说明中，不塞入摘要。
- 完成后核对费用未重复、个人应付款金额正确、已付款未重复及借贷平衡，简要报告凭证号、状态和金额。
